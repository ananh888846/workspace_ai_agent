# Acceptance Tests — Migration 021 → 030

Kiểm tra production SQL của Migration 021 → 030 trên PostgreSQL 18+ sau khi Migration 001 → 020 đã chạy thành công.

- AT-021 Observation FK
- AT-022 Event tenant isolation
- AT-023 Activity Session tenant isolation
- AT-024 Activity tenant isolation
- AT-025 Activity temporal CHECK
- AT-026 Message conversation FK
- AT-027 Message token CHECK

## Cách chạy

PowerShell:

```powershell
Get-Content .\database\tests\acceptance_021_030.sql | docker exec -i workspace-ai-agent-postgres psql -U workspace -d workspace_ai_agent -v ON_ERROR_STOP=1
```

Điều kiện trước:
1. PostgreSQL 18+
2. Migration 001 → 020 đã chạy.
3. Database test sạch hoặc đúng baseline migration.
4. Docker container tên `workspace-ai-agent-postgres`.

Test dùng transaction và kết thúc bằng `ROLLBACK`, không giữ fixture.
